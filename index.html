云同步设置

开启后，你的交易数据会加密上传到免费云端存储，电脑和手机打开同一个工作台即可自动同步。数据使用你设置的同步口令加密，口令只有你知道，云端服务商也无法读取明文。
获取方式：① 打开 jsonbin.io 用邮箱注册（免费）→ ② 登录后进入 API KEYS 页面 → ③ 点击 Create 生成 Master Key → ④ 复制粘贴到这里
首次使用点击「创建云存储」自动分配，无需手动填写；换设备时填写同一个 Bin ID 即可互相同步。
两台设备必须填写相同口令才能互相同步。请牢记口令，忘记后将无法解密云端数据（建议记在密码管理器里）。
